Funcionalidades

Tudo que um escritório precisa

Desenvolvido com base no fluxo real de trabalho contábil — não em suposições.

⚡

Conversão em lote

Converta dezenas de PDFs de uma vez. Todos os arquivos são entregues em um único ZIP organizado por banco e competência.

🔀

OFX e CSV

Exporte para OFX (compatível com a maioria dos sistemas contábeis) ou CSV para Excel e Google Sheets. No CSV, escolha por mês ou arquivo único.

🔍

Detecção automática

O formato do extrato é identificado automaticamente. Não é preciso indicar o banco — basta fazer upload do PDF.

📅

Extratos multicompetência

PDFs que abrangem mais de um mês (como os do BTG) são separados automaticamente por competência.

🔒

100% local

O processamento acontece inteiramente na sua máquina. Nenhum arquivo, dado ou extrato é enviado para qualquer servidor.

🖥

Interface simples

Drag-and-drop, seleção de banco, download automático. Funciona em qualquer navegador, sem instalação adicional.

Privacidade

Seus documentos nunca saem da sua máquina

PDF entra, arquivo OFX ou CSV sai. Nenhum dado é armazenado, registrado ou transmitido. Ideal para escritórios que lidam com informações financeiras confidenciais de clientes.

Como funciona

Pronto em 4 passos

Sem configuração, sem cadastro, sem dependências em nuvem.

01

Instale

Clone o repositório e rode pip install -r requirements.txt. Python 3.8+ é suficiente.

02

Abra no navegador

Execute python app.py e acesse localhost:5050. A interface carrega automaticamente.

03

Faça o upload

Arraste os PDFs para a área de upload. O banco é detectado automaticamente — não é necessário selecionar.

04

Baixe o resultado

O arquivo OFX ou CSV começa a baixar imediatamente. Para múltiplos arquivos, um ZIP é gerado automaticamente.

Pronto para começar?

O código é aberto. Instale, teste com seus extratos e contribua com novos bancos.
